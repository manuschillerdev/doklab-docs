Doklab APT repository

Debian and Ubuntu packages for amd64 and arm64.

Signing key fingerprint: 0EA730524EECD1C1E1BA4BF9B59164E721942879

Verify the signing key fingerprint against the Doklab installation documentation, then run:

sudo apt update
sudo apt install ca-certificates curl
sudo install -d -m 755 /etc/apt/keyrings
curl -fsSL https://manuschillerdev.github.io/doklab-docs/apt/doklab.asc | sudo tee /etc/apt/keyrings/doklab.asc > /dev/null
echo 'deb [signed-by=/etc/apt/keyrings/doklab.asc] https://manuschillerdev.github.io/doklab-docs/apt stable main' | sudo tee /etc/apt/sources.list.d/doklab.list
sudo apt update
sudo apt install doklab

The repository includes pinned SOPS and vals dependencies. Docker is required only on daemon hosts.
